# Telegram News Digest Bot

An automated Python bot that collects news from RSS feeds and delivers a structured daily news digest to Telegram.

## Features
- Collects news from multiple RSS feeds.
- Filters articles published within the last 24 hours.
- Groups news by topic.
- Selects a main image and short description for each topic.
- Generates a structured Telegram message.
- Includes a dry-run mode for testing without sending messages.

## Technologies
- Python
- RSS feeds
- HTML parsing
- Telegram Bot API
- Requests
- Feedparser

## Purpose
Built to automate news monitoring and make information easier to consume through a concise, topic-based Telegram digest.
